# 五子棋 iOS 游戏

一款完整的 iOS 五子棋游戏，支持人机对战，带有个人统计页面。

## 功能特点

### 游戏功能
- **人机对战**：与 AI 进行五子棋对弈
- **三种难度**：简单、中等、困难三个难度级别
- **智能 AI**：基于评分系统的五子棋 AI，支持威胁识别和棋型评估
- **选择执棋**：可以选择黑棋（先手）或白棋（后手）
- **悔棋功能**：支持悔棋重新开始
- **精美 UI**：使用 SwiftUI 构建的现代化界面

### 统计功能
- **游戏记录**：自动保存每局游戏的详细记录
- **胜率统计**：实时显示总场次、胜率等数据
- **连胜追踪**：记录最长连胜和当前连胜
- **时长统计**：统计总游戏时长和平均时长
- **难度分析**：按难度统计胜率
- **历史记录**：查看最近的游戏记录

## 核心实现

### 游戏逻辑

游戏逻辑在 `GameBoard.swift` 中实现：
- 15x15 标准五子棋棋盘
- 支持胜负判断（横、竖、斜四个方向）
- 平局检测
- 获胜连线高亮显示

### AI 算法

AI 算法在 `GomokuAI.swift` 中实现，包含：

1. **简单难度**：随机选择靠近已有棋子的位置
2. **中等难度**：
   - 检测一步获胜机会
   - 防守对手的获胜威胁
   - 基础评分系统
3. **困难难度**：
   - 多重威胁检测（双三、双四）
   - 完整的棋型评分系统
   - 开口数评估
   - 候选位置优化

评分系统：
- 五连：100,000 分
- 活四：10,000 分
- 冲四：1,000 分
- 活三：1,000 分
- 眠三：100 分
- 活二：100 分
- 眠二：10 分

### 数据持久化

使用 `UserDefaults` 进行数据持久化：
- 保存游戏统计数据
- 保存最近 100 场游戏记录
- 自动加载和保存

## 使用方法

### 运行项目

1. 使用 Xcode 打开项目：
   ```bash
   open Wuziqi.xcodeproj
   ```

2. 选择目标设备（iPhone 或 iPad 模拟器）

3. 点击运行按钮或按 `Cmd + R`

### 游戏玩法

1. **开始游戏**：
   - 点击"对战"标签进入游戏
   - 点击"新游戏"开始对局
   - 直接在棋盘上点击落子

2. **设置选项**：
   - 点击右上角齿轮图标
   - 选择 AI 难度
   - 选择执棋颜色（黑棋先手）

3. **查看统计**：
   - 点击"统计"标签查看个人数据
   - 查看胜率、连胜、游戏时长等
   - 查看历史对战记录

## 开发说明

### 添加新功能

1. **添加新的 AI 难度**：
   - 在 `GomokuAI.swift` 中添加新的 `Difficulty` 枚举值
   - 实现相应的算法方法
   - 在 `SettingsView` 中添加选项

2. **扩展统计功能**：
   - 在 `GameStatistics.swift` 中添加新的统计字段
   - 更新保存/加载逻辑
   - 在 `StatisticsView.swift` 中添加显示

3. **自定义棋盘**：
   - 修改 `GameBoard.boardSize` 常量
   - 调整 `BoardView.swift` 中的布局参数
